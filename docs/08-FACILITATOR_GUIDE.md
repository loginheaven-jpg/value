# 08. 진행자 가이드

세션을 **진행하는 사람**을 위한 현장 문서입니다. 개발 문서가 아닙니다.

기술 배경은 `docs/02-PRODUCT_UX_PROCESS.md`(설계 의도), 설치는
`docs/05-LOCAL_SETUP_AND_MIGRATION.md`를 보십시오. 루트의 `USER_GUIDE.md`는 v1 기준이라
카드 수와 단계 설명이 현재와 다릅니다.

---

## 1. 준비 체크리스트

### 온라인·대면 공통

| 항목 | 확인 |
|---|---|
| 접속 주소 | 미리 공유합니다. 첫 화면에서 이름과 이메일을 입력합니다 |
| **이메일 정확도** | 결과를 다시 여는 **유일한 열쇠**입니다. 오타가 나면 되찾지 못합니다. 한 번 더 확인시키십시오 |
| 기기 | 휴대폰으로 충분합니다. 1단계는 한 손으로 넘기도록 설계했습니다 |
| 개인정보 안내 | 첫 화면에 수집 목적·보관 기간·삭제 문의처가 표시됩니다. 읽을 시간을 주십시오 |
| 중단 대비 | 진행 상태는 브라우저에 24시간 저장됩니다. 끊겨도 **같은 기기·같은 브라우저**면 이어집니다 |

### 대면 세션 추가

| 항목 | 확인 |
|---|---|
| 와이파이 | 동시 접속 인원을 감당하는지. 카드 데이터는 최초 1회만 내려받습니다 |
| 배터리 | 개인 작업 15분 + 공유 20분 동안 화면을 켜 둡니다 |
| 인쇄 | 결과를 종이로 쓸 계획이면 **데스크톱·태블릿**이 필요합니다(6절 참조) |

### 온라인 세션 추가

| 항목 | 확인 |
|---|---|
| 화면 공유 | 진행자가 1단계를 한 번 시연하면 설명이 절반으로 줍니다 |
| 소회의실 | 3절의 공유 시간에 맞춰 미리 열어 둡니다 |

---

## 2. 단계별 권장 시간

| 구간 | 시간 | 진행자가 볼 것 |
|---|---:|---|
| 워밍업 | 1분 | 이메일 입력·개인정보 안내 |
| 1단계 분류 | 4분 | 속도. 한 장에 오래 머무는 사람 |
| 2단계 | 3분 | 처음으로 '고르는' 단계입니다. 여기서 시간이 듭니다 |
| 3단계 | 3분 | 표정이 바뀌는 지점 |
| 4단계 쌍대비교 | 3분 | 빠르게 지나갑니다 |
| 최종 선택 | 2분 | 순위를 그대로 따르지 않아도 된다고 말해 주십시오 |

합계 16분입니다. 첫 화면의 "약 10-15분" 표기보다 조금 깁니다 — 1단계에서 개인차가 가장
크므로 **여유 있게 20분**을 잡으십시오.

---

## 3. 세미나 통합 흐름

| 구간 | 시간 | 내용 |
|---|---:|---|
| 개인 작업 | 15분 | 각자 진단을 끝냅니다. 먼저 끝낸 사람은 성찰 질문을 읽게 합니다 |
| 소그룹 공유 | 20분 | 2~3인. 세 가치와 **그 이유**를 나눕니다 |
| 전체 인사이트 | 15분 | 한두 명이 발표하고, 진행자가 공통점·차이를 짚습니다 |

소그룹에서는 "무엇을 골랐나"보다 **"무엇을 놓았나"**를 묻게 하십시오. 3단계에서 5개를
2개로 줄일 때 무엇을 내려놓았는지가 가장 깊은 재료입니다.

---

## 4. 1:1 코칭 사전과제로 쓰기

세션 전에 링크를 보내고 결과를 가져오게 합니다.

| 시점 | 진행자 |
|---|---|
| 세션 3일 전 | 링크 발송. "20분 정도 걸립니다. 조용한 때에 하세요" |
| 세션 당일 | 결과 화면 또는 인쇄물을 지참하게 합니다 |
| 세션 도입 | 세 가치를 **본인 말로** 설명하게 합니다. 카드 설명을 읽게 하지 마십시오 |
| 세션 중 | 4단계 비교 순위와 최종 3개가 다르면 그 차이를 묻습니다 |

좋은 질문: *"비교에서는 이게 위였는데 최종에서는 빼셨네요. 어떤 마음이었나요?"*

## 5. 진행 중 개입 문구

그대로 쓰셔도 됩니다.

> "고민이 길어지시나요? 그럼 일단 '글쎄'로 넘기세요. 나중에 다시 만납니다."

> "정답을 찾고 계신 것 같아요. 지금은 맞고 틀림이 없습니다. 몸이 반응하는 쪽으로 가시지요."

> "다 중요해 보이시죠? 그 느낌이 자연스럽습니다. 그중에서도 '더' 끌리는 쪽만 고르시면 됩니다."

### 1단계를 여는 말

1단계는 다른 단계와 화면이 다릅니다. 카드를 한 화면에 펼쳐 개수를 맞추는 것이 아니라,
**한 장씩** 보여주고 네·글쎄요·아니요 세 더미로 나눕니다. 목표 개수를 제시하지 않습니다.

> "지금부터 카드가 한 장씩 나옵니다. 개수를 세지 마세요. 몇 장을 골라야 한다는 기준은
> 없습니다. 마음이 반응하면 '네', 아니면 '아니요', 애매하면 '글쎄요'로 넘기세요.
> **한 장에 3초를 넘기지 마세요.**"

**개수를 말하지 마십시오.** '20개를 고르세요'라고 하면 참여자는 세기 시작하고, 세는 순간
'이게 정말 20위 안에 드나'를 따집니다. 그것은 반응이 아니라 계산입니다.

### 키보드 (PC 참여자)

← 아니요 · ↓ 글쎄요 · → 네 · Backspace 되돌리기. 화면 버튼 순서와 같습니다.
한 번 알려주면 눈에 띄게 빨라집니다.

### 한 바퀴가 끝난 뒤

'네' 더미의 장수에 따라 갈립니다.

| '네' 장수 | 화면 | 진행자 |
|---|---|---|
| 12장 미만 | 보충 화면 | *"조금 더 고르시면 됩니다. 아까 망설이셨던 카드부터 보여드릴게요."* |
| 12~24장 | 2단계로 | — |
| 24장 초과 | 재분류 권유 | 줄이기를 권하되 **거절해도 된다**고 함께 말해 주십시오 |

24장을 넘기면 화면이 세 갈래를 줍니다 — 검토 화면에서 줄이기(권장) · 한 번 더 나누기 ·
그대로 가기. 세 번째 버튼에는 장수가 적혀 있습니다("38장 그대로 2단계로 가기"). 시간이
촉박하면 그것을 눌러도 됩니다. 다만 2단계가 그만큼 길어집니다.

### 진행자가 하지 말아야 할 것

- **개수를 말하지 마십시오.** 1단계에 목표 개수가 없는 것은 설계입니다.
- **'맞는 가치'를 시사하지 마십시오.** 진행자가 특정 카드에 반응하면 참여자가 따라갑니다.
- **쌍대비교 결과를 정답처럼 말하지 마십시오.** 참고 정보입니다.
- **결과를 대신 해석하지 마십시오.** 성찰 질문은 참여자가 답하는 것입니다.

## 6. 트러블슈팅

### 저장 만료

| 증상 | 대응 |
|---|---|
| 진행 중 화면이 닫혔다 | 같은 기기·브라우저로 다시 접속하면 **24시간 이내**는 이어집니다 |
| 24시간이 지났다 | 처음부터 다시 합니다. 두 번째는 훨씬 빠릅니다 |
| 다른 기기에서 이어 하고 싶다 | **불가능합니다.** 진행 상태는 그 브라우저에만 있습니다 |
| 시크릿 창을 썼다 | 창을 닫으면 사라집니다. 일반 창으로 다시 하게 하십시오 |

### 되돌리기

| 증상 | 대응 |
|---|---|
| 1단계에서 잘못 눌렀다 | 화면 아래 **'방금 것 되돌리기'**. PC는 Backspace |
| 여러 장을 되돌리고 싶다 | 한 장씩만 됩니다. 많이 되돌려야 하면 한 바퀴 끝난 뒤 검토 화면에서 고칩니다 |
| 2단계에서 1단계로 가고 싶다 | 우측 하단 '이전 단계'. 고른 카드를 검토 화면에서 더하거나 뺄 수 있습니다 |
| 키를 누르고 있었더니 여러 장이 넘어갔다 | 자동 반복은 무시하도록 되어 있습니다. 그래도 넘어갔다면 되돌리기로 한 장씩 복구합니다 |

### 재진단·결과

| 증상 | 대응 |
|---|---|
| 처음부터 다시 하고 싶다 | 결과 화면의 '다시 시작'. 이름과 이메일은 유지됩니다 |
| 결과가 안 보인다 | '내 결과 보기'에서 **입력했던 이메일 그대로** 조회해야 합니다 |
| 카드 설명이 안 와닿는다 | 설명은 예시입니다. 참여자 자신의 말로 바꿔 보게 하십시오 |
| 목록에 없는 가치를 쓰고 싶다 | 결과 화면에서 하나를 교체할 수 있습니다. 다만 **먼저 물어보십시오** — *"목록의 어떤 카드도 그 자리에 못 들어가나요?"* 대개 비슷한 카드가 있고, 그것을 찾는 과정이 코칭입니다 |

### 인쇄의 한계 — 미리 아셔야 합니다

**인쇄 버튼은 데스크톱·태블릿(가로 768px 이상)에서만 보입니다.**

`window.print()`가 iOS Safari와 카카오톡 인앱 브라우저에서 제대로 동작하지 않습니다.
참여자 다수가 휴대폰으로 접속하므로 **인쇄는 사실상 데스크톱 전용 기능**입니다.

| 상황 | 대응 |
|---|---|
| 휴대폰 참여자 | **'복사하기'가 주 동선입니다.** 결과를 복사해 메모장이나 메시지에 붙여 두게 하십시오 |
| 종이가 꼭 필요한 세션 | 진행자 PC에서 참여자별로 인쇄하거나, 참여자에게 PC 접속을 미리 안내하십시오 |
| 카카오톡 링크로 들어왔다 | 인앱 브라우저입니다. '다른 브라우저로 열기'를 안내하십시오 |

인쇄물에는 **접어 둔 카드의 성찰 질문까지 모두** 나옵니다. 화면에서 하나만 펼쳐 두었더라도
종이에는 여섯 개 질문이 전부 담깁니다. 버튼과 안내 문구는 인쇄되지 않습니다.
브라우저 인쇄 대화상자의 "PDF로 저장"을 쓰면 파일로 남길 수 있습니다.
