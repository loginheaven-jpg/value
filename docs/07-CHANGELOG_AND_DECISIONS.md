# 주요 변경 이력과 제품 의사결정

## 1. 서비스의 핵심 진화

| 시기·단계 | 변경 | 결정 이유 |
|---|---|---|
| 초기 | 가치 카드 소팅 서비스 구축 | 한국어 가치 언어로 자기 탐색을 지원 |
| 카드 목록 정리 | 80개에서 72개 정식 가치로 축소·설명 보완 | 유사·중복 가치를 줄이고 한국 문화 맥락을 반영 |
| 진단 방식 개선 | 5개→3개 직접 선택 대신 쌍대비교와 최종 자유 선택 도입 | 미세한 우선순위를 관찰하되 알고리즘이 결정을 강제하지 않게 함 |
| 결과 관리 | 이름·이메일 기반 DB 저장·이력 조회·운영 화면 추가 | 재진단과 운영 활용 지원 |
| 결과 저장 안정화 | 세션 플래그로 무한 DB 저장 방지 | effect 재실행으로 인한 중복 저장 이슈 대응 |
| 카피 개선 | 1~5단계·인트로·결과를 직관·자기다움 중심으로 개편 | 당위가 아니라 내적 끌림에 따른 선택 유도 |
| 73번 카드 제거 | `나만의 가치 추가하기` 플레이스홀더를 카드 데이터에서 삭제 | 정식 카드 수를 72개로 유지하고 최초 흐름의 혼선을 줄임 |

## 2. 현재 카피의 기준

| 위치 | 기준 문구·의도 |
|---|---|
| 1단계 | “마음이 더 끌리는 카드 20개” — ‘그래야만 한다’는 당위를 내려놓음 |
| 2단계 | “이것 없이는 정말 나답지 않아”인 10개 — 자기 동일시 강화 |
| 3단계 | 삶에서 “절대 타협할 수 없는” 5개 — 핵심성 강화 |
| 쌍대비교 | “머리가 아닌 가슴으로, 직관적으로” — 정답 없음 안내 |
| 최종 선택 | “당신의 인생을 대표할 3가지” — 순위는 참고, 최종 선택은 자유 |
| 결과 | “당신을 발견했습니다” — 가치가 의사결정의 나침반이라는 메시지 |

## 3. 유지해야 할 제품 원칙

> 가치 진단은 사람을 점수화하거나 정답을 판정하는 도구가 아니라, 사용자가 이미 가지고 있는 언어·경험·우선순위를 알아차리도록 돕는 성찰의 과정이다.

다음 원칙은 기능·카피·분석 기능이 늘어나도 유지합니다.

| 원칙 | 해석 |
|---|---|
| 비판정성 | 결과를 우열·성숙도·성격 유형으로 해석하지 않음 |
| 자율성 | 최종 선택은 사용자의 자유를 보장 |
| 투명성 | 저장·이메일·분석의 목적과 범위를 분명히 알림 |
| 재방문성 | 시간에 따른 가치 변화를 자연스러운 성찰로 존중 |
| 문화적 적합성 | 한국어의 관계·공동체·정서 맥락을 고려 |

## 4. 세미나 자료와의 관계

이 서비스는 가치 발견 그룹 코칭 세미나의 디지털 진단 도구로 활용될 수 있습니다. 세미나 자료의 핵심 흐름은 가치 발견 → 신념 탐색·재구성 → 삶의 적용 → 선언·실천입니다. 그러나 웹 서비스는 현재 **가치 발견과 결과 성찰**에 초점을 두며, 신념 재구성·WOOP·책임 파트너 기능을 제품 기능으로 구현하지는 않았습니다.

향후 세미나용 확장 기능을 만들 때는 개인 진단과 집단 워크숍 모드를 분리하고, 참가자의 결과를 퍼실리테이터에게 공유하는 경우 별도 동의·열람 권한·보존 기간을 설계해야 합니다.
